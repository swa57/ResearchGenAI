# ResearchGenAI

An AI-powered research paper generation platform built using Gemini AI and Streamlit.

## Overview

ResearchGenAI is an intelligent web application designed to simplify academic and technical research writing through Generative AI. The platform enables users to generate structured research content, abstracts, and topic-based documentation with an interactive and user-friendly interface.

The application leverages Gemini AI to assist users in accelerating the research drafting process while improving productivity and content quality.

---

## Key Features

* AI-generated research paper content
* Automated abstract generation
* Topic and keyword-based research drafting
* Interactive Streamlit web interface
* Gemini AI integration for intelligent text generation
* Clean and responsive user experience

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/swa57/ResearchGenAI.git
```

### 2. Navigate to the Project Directory

```bash
cd ResearchGenAI
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Configuration

Create a `.env` file in the root directory and add your API key:

```env
GROQ_API_KEY=your_api_key_here
```

---

## Run the Application

```bash
streamlit run app.py
```
